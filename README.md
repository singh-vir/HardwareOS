# HardwareOS

HardwareOS is the desktop workspace for building firmware with AI assistance, working with boards and parts, and keeping project notes next to your code.

This repository hosts official desktop releases and the public issue tracker. Source code lives elsewhere.

## Download

Installers for the latest release:

| Platform | Download |
| --- | --- |
| macOS (Apple silicon) | [Download](https://api.hardwareos.ai/v1/desktop/download/macos-arm64) |
| macOS (Intel) | [Download](https://api.hardwareos.ai/v1/desktop/download/macos-x64) |
| Windows | [Download](https://api.hardwareos.ai/v1/desktop/download/windows) |
| Linux | [Download](https://api.hardwareos.ai/v1/desktop/download/linux) |

Or open the [latest release](https://github.com/singh-vir/HardwareOS/releases/latest) and pick the package for your machine.

macOS builds are signed with Developer ID. If Gatekeeper prompts on first launch, open System Settings → Privacy & Security and allow HardwareOS.

## Updates

Installed builds check for updates automatically. You can also use **Settings → Updates → Check for updates**. Updates download from the official release channel and install on restart.

## Issues

Use [GitHub Issues](https://github.com/singh-vir/HardwareOS/issues) for bugs, hardware support requests, and feature ideas. Include your OS version, HardwareOS version (Settings → Updates), and board or toolchain details when relevant.
